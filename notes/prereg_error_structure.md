# Unsupervised error-structure check

Exploratory question fixed before outcome extraction: do false essentiality predictions form a localized cluster in the frozen v2 feature space, or are they diffuse? Inputs: the same 1,249 aligned genes and frozen 20 v2 features from the learner sensitivity study. Standardize using all genes without labels. UMAP embeds the standardized feature matrix to 2D using fixed n_neighbors=30, min_dist=0.1, seed=17. HDBSCAN fits labels to the embedding with min_cluster_size=25, min_samples=10. PyOD KNN computes an unsupervised outlier score in standardized 20D features (k=20). Only after fitting, compare clusters' prevalence of false positives among the top-100 non-essential v2-ranked genes with one-sided Fisher tests corrected BH. Test whether top-100 error-priorities show higher PyOD outlier scores than the rest via Mann-Whitney; no direction assumed as a success criterion. Report every cluster and noise, sizes, error counts, p/q and non-significant outcomes. These packages perform distinct algorithms on real scores, not mere plotting. Do not infer a cell state from a 2D embedding. This is exploratory, no independent data.
