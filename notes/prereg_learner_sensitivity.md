# Learner sensitivity, fixed before comparison

Question: Is the v2 external-feature gain robust to model family, or does it depend on logistic regression? Use the same aligned 1,249-gene data and fixed 3-fold stratified split (seed 7), the frozen v2 feature columns as in scripts/run_xgb_shap.py, no tuning after observing results. Compare out-of-fold AUROC/AUPRC and paired bootstrap (seed 11, 1,000 resamples) against the committed v2 LR scores. Four distinct packages must execute scientific steps rather than be listed: LightGBM and CatBoost train models, imbalanced-learn runs train-fold-only random oversampling with logistic regression, SHAP explains a trained CatBoost model. No winner selection; all results and negative results remain. This is exploratory, not an independent biological validation. All original gene labels and scores remain private in repository.
