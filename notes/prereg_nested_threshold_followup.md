# VC2 verdict-01 nested threshold follow-up, frozen 27 September 2026 before this run

The old v1/v2 scores, five-rung G2 FAIL, and score-lineage leak audit have ALREADY been inspected. This is a NEW exploratory evaluation with an explicitly narrower, label-free feature recipe. It does not amend or repair the original G2 gate, and its reuse of the Gerdes accession prevents calling it an independent external validation. No optional model, threshold or split is chosen after the following scores are seen.

**Question:** Does an explicitly nested threshold procedure produce a reproducible held-out hard-call contrast against a label-free FBA comparator on the same Gerdes overlap, once reused supervised base scores (CNN, GNN, k-mer OOF) are excluded?

**Inputs:** Freeze SHA256 of `results/aligned_predictions_all_models.csv` and `results/external_features.csv` at execution. Merge by bnumber one-to-one; no imputation other than missing external feature values to zero, which is the original v2 convention. Features: `fba_min`, `fba_rich` and `extc_clean`, defined exactly by `scripts/run_ensemble_v2.py`: all external columns except bnumber, `string_*`, `up_annot`, `pax_log_ppm`, `cai`, `gc3`. This still uses public annotations compiled after essentiality literature, so absence of direct label leakage is not established. It is a restricted model rather than a rerun of the old full stack.

**Nested protocol:** Outer `StratifiedKFold(3, shuffle=True, random_state=7)` in aligned row order. For each outer-training partition, inner `StratifiedKFold(3, shuffle=True, random_state=17)` produces inner OOF LR scores using only the respective inner-training genes. Pipeline: `StandardScaler` then `LogisticRegression(class_weight='balanced', C=0.5, max_iter=4000, random_state=7)`; no supervised preprocessing outside a training fold. Select one threshold on inner OOF scores by maximal Matthews correlation over 199 quantiles from 0.005 through 0.995; ties favor the threshold nearest 0.5, then the smallest threshold if still tied. Fit the same pipeline to the entire outer-training partition, and apply its frozen threshold to outer-evaluation scores once. No outer-evaluation labels or scores enter threshold selection or model fitting.

**Comparator:** `fba_min > 0.5` fixed a priori and label-free. Report pooled outer AUROC, AUPRC, F1, MCC, model-only-correct b and comparator-only-correct c, exact two-sided binomial McNemar p, and all per-fold thresholds and sample counts. Also report the old failed gate unchanged. No pass/fail gate is attached to this retrospective same-accession follow-up. Numerically favorable results cannot establish independent biological validation or the original benchmark-beat claim. Record a negative outcome even if inconvenient. Do not reinterpret p>=0.05 as evidence of equivalence.
