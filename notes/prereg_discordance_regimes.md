# VC2-R2: prospective biological-regime discordance test

Date 2026-09-26. Status: DESIGN LOCK, not scored. Motivated by ChatGPT judge round 01 (verbatim record in `results/judge_rounds/`). This is a novelty analysis, not an amendment of the failed G2 gate, and the already inspected Gerdes OOF comparison is discovery/exploratory data, not independent confirmation.

Hypothesis: model-only corrected errors over FBA are enriched in genes with high *regulatory* complexity and weak metabolic constraint. Mere STRING interaction degree is NOT a transcription-regulatory annotation; KEGG membership is NOT flux constraint. Thus do not substitute either as proof of the mechanism.

Dataset and feature protocol: obtain a versioned external E. coli K-12 transcription-factor-target network (RegulonDB or equivalent; note retrieval URL, release, date, licensing, exact downloaded file SHA256) and map target gene bnumbers with a mapping audit. Regulatory score is the count of distinct direct TF regulators per gene. Metabolic constraint is the same model's raw fba_min_frac (pre-outcome model output), with direction defined in the locked fba_min generation code; inspect its definition before setting low/high cutoffs. For held-out independent replication, use a second essentiality screen of E. coli with no genes/labels used to select these definitions, and train-only fit of any newly trained predictor. If no independent outcome exists, only an exploratory hypothesis-generating report is allowed.

Predeclare thresholds on an annotation-only reference: high regulation = upper quartile of mapped TF count; low constraint = lower quartile of the metabolic-constraint magnitude (definition locked from the actual generation method). At ties use strict `>` for high regulation and `<=` for low constraint; report all unassigned genes. Stratify four cells; main contrast is Hreg/Lconstraint vs other mapped genes, comparing model-only correct minus FBA-only correct per stratum, with exact permutation of stratum labels preserving essentiality prevalence and expression quantile bins. Report cell sizes, AUROCs (if both classes), two-sided uncertainty interval for paired advantage, and enrichment odds ratio. An exact implementation must specify random seed and at least 10,000 permutations, avoiding a post-hoc favorable one-sided tail. A secondary control matches on gene expression proxy pax_log_ppm, class, and gene length; a FBA-only predictor addresses feature-source advantage. Random partitions retaining cell sizes form a null control.

Falsification: reject the mechanistic enrichment hypothesis if enrichment is absent or reverses, if matched-control enrichment disappears, or if random partitions yield similar enrichment. Replication requires the predeclared enrichment direction and interval excluding null on independent screen; the already-open Gerdes OOF may only scope feasibility. Report no clinical implication. G2 remains literal FAIL; no retroactive amendment or victory claim. Avoid applying the original 0.666 benchmark to this stratified analysis.

Open inputs before score: validated regulatory source file and mapping; inspect fba_min_frac orientation/definition; untouched external screen and overlap policy; fold lineage and leakage audit; comparator threshold flatness check; lock executable manifest and test suite. If data are unavailable, record blocked, not positive.
