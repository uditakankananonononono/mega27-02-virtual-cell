Never use the already inspected 48 outcomes as a confirmatory holdout for a regression.

Question: can pre-perturbation structural features of biomass components explain which objective requirements create in-silico essentiality fragility? Initial feasibility uses the iJN1463 snapshot. Record raw source URL and SHA256, objective direction and medium. Candidate pool: every negative biomass stoichiometric coefficient in the single WT biomass reaction. For each metabolite, compute before rescoring: absolute coefficient, number of associated non-biomass reactions, number of distinct gene-associated reactions, whether any exchange permits uptake, and baseline WT flux through its producing reactions. These are explicit proxies, not full pathway redundancy or causation. Screen target is the count of original baseline-essential gene knockouts that regain >=95% of original WT after deleting that ONE biomass coefficient. This makes every target comparable by perturbation cardinality and avoids contrasting a three-metabolite MoCo bundle with singles.

First run will be exploratory because the 48 coefficient-matched targets have already been inspected. Compute all remaining individual biomass terms, preserve zeros and failures, and audit target definition. Do not fit and claim a predictive model on the same 102 components as validation. Biological knockout screens and richer reaction-network features remain separate tests. If compute or source provenance prevents an external family, report that blocker instead of relabeling in-sample fit as generalization.

The immediate novelty addition before outcomes: an executable candidate/feature manifest with immutable model hash, baseline feature definitions, full term inventory, separation of previously observed 48 from not-yet-scored terms, and planned negative-control prediction protocol.
